# XIV Vault 1.1.0-beta.1

This is a beta for testers. Stable 1.0.0 stays the main download on the website and in winget. This beta makes backups in the same format as 1.0, with the same safety backup, hash checks and running-game checks.

## What's new

- **Install missing plugins.** After a restore, XIV Vault can install the plugins your Dalamud settings list but this PC doesn't have yet. Each plugin keeps its old ID, so your collections and on/off states line up again.
- **Get beta versions** in Settings → Updates lets a copy receive later betas.

## Installing

Download `xiv-vault-setup-win-x64.exe` from this release and check it against `SHA256SUMS`. Version 1.0 can't find betas, so the first beta is a manual download. To get later betas, turn on **Settings → Updates → Get beta versions** and select **Check Now**. The switch starts off. If you turn it off again, XIV Vault keeps this version until a newer stable release arrives. The portable copy and the command line have no updater, so download new versions of those by hand.

## How plugin installs work

- In the restore review, **Install missing plugins** is on whenever Dalamud settings are restored. The review lists the missing plugins XIV Vault will look for. The list can include plugins you removed in game, because the backup still names them.
- XIV Vault looks in Dalamud's official repository. Custom repositories from your backup are listed by host and start unticked, so tick only the ones you trust. As Dalamud warns, plugins have full control over your PC.
- A plugin whose settings you leave out of the restore isn't installed.
- XIV Vault downloads each plugin's current version. Plugin files never come from a backup, and XIV Vault never runs them. Plugins you already have are left alone.
- Everything is downloaded and checked before anything on your PC changes. Then XIV Vault makes the safety backup, restores your settings and installs the plugins.
- **Restore complete** lists the plugins that were installed, and any that weren't with the reason, so you can install those from `/xlplugins` in the game.
- If Dalamud hasn't finished downloading on a new PC, no plugins are installed. Open XIVLauncher, let it finish, close it and restore again.
- Restoring a Pre-Restore Safety Backup installs nothing and doesn't remove plugins.
- Stable versions never install plugins, and neither does a restore into XIVLauncherCN.

## What it downloads

Plugin lists and downloads come from `kamori.goats.dev`, which redirects downloads to `raw.githubusercontent.com`, and from the custom repositories you tick and the hosts their downloads point to. Those hosts see which plugins are downloaded, as they do when you use Dalamud's plugin installer. XIV Vault sends nothing about you, your characters or your backups.

## Trying a restore on a new PC

1. On the new PC, install XIVLauncher and start the game once so Dalamud finishes downloading. Then close the game and XIVLauncher. Keep your old PC's setup and its backups as they are.
2. Install this beta. Settings and the sidebar show `1.1.0-beta.1`.
3. In **Restore**, pick your backup, or use **Choose a backup file…** to open one from another folder.
4. In the review, keep **Dalamud settings** and **Install missing plugins** on, and tick the custom repositories you trust. Leave **System settings** out if this PC has a different screen.
5. Continue to the safety check and select **Restore Configuration**.
6. Start the game. Check that your plugins load with their settings, collections and on/off states, and that your HUD, hotbars, macros and keybinds came back. Install anything **Restore complete** listed from `/xlplugins`.

## Reporting back

Say what worked and what didn't in [a new issue](https://github.com/hazeliscoding/xiv-vault/issues/new/choose), with the report from **Diagnostics → Copy Diagnostic Report**. The report holds paths, versions and results only. Please don't attach a backup, configuration files or logs, since they can hold details about your characters.
