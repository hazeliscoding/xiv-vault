# XIV Vault 1.1.0-beta.1

Testing prerelease for a clean-PC restore. Stable 1.0.0 remains the main download. This beta keeps the existing backup format, safety snapshots, hash checks and running-game checks.

## Install and updates

Install `xiv-vault-setup-win-x64.exe` from this prerelease and check it against `SHA256SUMS`. Version 1.0 cannot discover betas. In the beta, turn on **Settings → Updates → Get beta versions** and select **Check Now** to receive later betas. The switch starts off. Turning it off keeps this version until a newer stable release arrives. Portable copies and the CLI require manual downloads.

## Missing plugins

The review offers **Install missing plugins**, on by default when restoring Dalamud settings. It lists plugins to look for, including any removed plugins still named in the backup. It checks Dalamud's official repository and only the custom repositories you tick. Custom choices start unticked and show host names. Plugins whose settings you leave out are not installed; plugins with no settings in the archive can still install.

Downloads use the current compatible versions, never binaries from the backup. XIV Vault preserves plugin IDs so restored collections and on/off states can find them. Existing plugins are left alone. Completion lists installed plugins and gives reasons for anything missing. If Dalamud has not downloaded yet, open XIVLauncher, let it finish, close it and restore again.

Requests go to `kamori.goats.dev` for the official list and downloads (which redirect to `raw.githubusercontent.com`), and to chosen custom repositories and their download hosts. Hosts see which plugins are requested. No configuration contents, character information or backups are sent. Plugins are code: choose only developers you trust. XIV Vault checks packages but does not execute them.

Downloading and checking finishes before the safety backup and settings restore. Restoring a Pre-Restore safety backup installs nothing and leaves any newly installed plugins on disk. Plugin installation is unavailable in stable builds and for XIVLauncherCN.

## HummingOak's clean-PC run

1. Keep the original backup and original PC's setup intact. Install XIVLauncher on the clean PC, let Dalamud finish downloading, then close XIVLauncher and FFXIV.
2. Install this beta. Confirm **Settings** and the sidebar show `1.1.0-beta.1`. Choose the backup folder, or use **Restore → Choose a backup file…**.
3. In the review, leave **Dalamud settings** and **Install missing plugins** on. Tick only the custom repository hosts you recognize. Leave **System settings** out if the new PC has a different screen. Record the missing-plugin count and selected host names, without sharing repository URLs or character folder names.
4. Continue through the safety checks and choose **Restore Configuration**. Confirm a Pre-Restore safety backup appears. Note the installed count and any plugins listed with a reason. If Dalamud is not ready, follow the message and repeat the restore.
5. Open XIVLauncher and enter the game. Check plugins load with their settings, collections and on/off states, and check the HUD, hotbars, macros and keybinds. Use `/xlplugins` for anything the completion screen lists as not installed.
6. Report what passed or failed, the version, and the Diagnostics report. Do not send a whole backup, configuration contents or raw logs with character information. A repeat restore should leave already installed plugins alone.

The owner's fresh-folder test passed for 68 plugins, including 12 custom repositories. HummingOak's clean-PC result and the installed-update rehearsal are still pending; this document is not a record that they passed.
